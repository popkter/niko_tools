# NikoTools 脚本参数模板

保留用户指定的脚本语言和业务逻辑，将运行前的用户输入改为插件参数表单。插件先进行字面文本替换，再启动脚本；进程运行后不支持交互式输入。

## 参数识别与声明

- 将 `read`、`input()`、`Read-Host`、`set /p` 等交互输入，以及用户明确要求可配置的文件、目录、模式、开关等，转换为参数模板。内部计算变量、循环变量、系统环境变量和固定常量不自动转换。
- 优先在脚本开头声明 `var id=${显示名称@类型:默认值或选项}`，正文通过 `${id}` 引用。一个参数只声明一次，可以多次引用。
- `var` 声明必须单独占一行，定义不能跨行。声明行由插件移除，不是 Bash、PowerShell 或 Python 的变量声明。
- 内部 id 和显示名称只支持中文、字母、数字、下划线，不含空格。内部 id 推荐使用有意义的英文名称。
- 类型或默认值未给定时，根据输入用途选择控件；不为真实文件路径、令牌或密码凭空编造默认值。

## 支持的控件

| 类型 | 声明示例 | 规则 |
| --- | --- | --- |
| `@text` | `var name=${名称@text:示例}` | 单行字符串；显式文本不自动推断选项 |
| `@multiline` | `var notes=${说明@multiline}` | 保留用户输入中的换行；声明本身保持单行 |
| `@integer` | `var count=${数量@integer:3}` | 执行前校验整数，替换结果仍是文本 |
| `@number` | `var ratio=${比例@number:0.5}` | 执行前校验整数或小数，替换结果仍是文本 |
| `@boolean` | `var enabled=${启用@boolean:true}` | true/1 默认勾选，false/0 或无默认值时不勾选；输出 `True` 或 `False` |
| `@choice` | `var mode=${模式@choice:开启=1\|关闭=0}` | 下拉单选，默认第一项，替换为实际值 |
| `@radio` | `var target=${目标@radio:开发=dev\|生产=prod}` | 横向单选按钮组，选项及输出规则同下拉框 |
| `@file` | `var input=${输入文件@file}` | 选择单个文件或手工输入路径；不自动检查存在性 |
| `@dir` | `var output=${输出目录@dir:./output}` | 选择目录或手工输入路径；不自动创建目录 |
| `@secret` | `var token=${访问令牌@secret}` | 默认遮蔽，支持显示/隐藏和保存默认值；替换时使用实际文本 |

表格中的 `\|` 仅用于 Markdown 表格转义，实际脚本写 `|`。选项用 `显示标签=实际值`，例如 `${模式@choice:开启=1|关闭=0}`；支持一个或多个选项，标签不能为空或重复，实际值不能为空。选项默认选第一项，需要特定默认选项时将它放在第一位。

普通输入冒号后为默认值；省略冒号表示不提供内联默认值。已有 `${名称}`、`${名称:默认值}`、`${名称=默认值}`、`${模式:开启=1|关闭=0}` 和 `Var`、`pVal` 声明继续兼容，新脚本优先使用显式类型和小写 `var`。

## 替换与执行约束

- 插件识别正文、参数数组、环境变量值和工作目录中的占位符，解释器路径不参与解析。重复定义同一 id 的类型、默认值或选项必须一致。
- 占位符定义不支持花括号嵌套；没有 `[required=...]`、`[min=...]`、`[default=...]` 等属性语法，也没有 `@files`、`@date` 等类型。若需要可选参数，另附参数元数据 `required: false`；默认参数必填，即使标题不显示星号。
- 参数替换不会自动添加引号或做 Shell 转义。根据目标语言处理空格、引号、反斜杠和多行内容；双引号不保证任意输入都安全。复杂或不可信内容优先通过插件的环境变量配置或独立参数数组传递，并附上对应配置。
- 保留脚本原生变量的语义。Bash 原生 `${变量}` 同样会被插件识别，普通运行时变量优先写 `$变量`，不要把内部变量误声明为用户输入。
- 将整数、数字和布尔文本按脚本语言需要进行转换。不能在 Bash 中把 `True` 当作可执行命令，也不能在 Python 中用 `bool("False")` 判断开关。
- 密码控件只遮蔽界面，不加密存储。除非用户要求，不把真实密码设为内联默认值，也不增加打印密码的逻辑。

## Bash 转换示例

用户需要选择输入文件、输出目录、运行模式和缓存开关时：

```bash
var input=${输入文件@file}
var output=${输出目录@dir:./output}
var mode=${运行模式@choice:快速=fast|完整=full}
var cache=${启用缓存@boolean:true}

# 示例使用普通受信任输入；实际业务命令沿用原脚本。
echo "输入文件：${input}"
echo "输出目录：${output}"
echo "运行模式：${mode}"
if [ "${cache}" = "True" ]; then
    echo "缓存已启用"
fi
```

## 交付

输出完整、可粘贴到插件的脚本，并注明执行类型。需要参数数组、环境变量或参数元数据时，单独附上对应 JSON 配置；不要把这些配置混进脚本正文。检查所有插件引用均有对应定义、控件类型正确、选项值符合业务命令、原脚本内部变量未被误替换。
